# T0H1 Scanner V0.2

T0H1 Scanner is a native Android utility built with Kotlin, Jetpack Compose, and Chaquopy.

## What this version focuses on

- Cleaner dashboard layout
- Bilingual support for English and Persian
- Better result cards and scan summaries
- Persisted scan drafts and settings
- Native Android UI with a professional dark theme

## Project layout

- `app/src/main/java/com/t0h1/scanner/`
- `app/src/main/python/scanner/`
- `app/src/main/res/values/`
- `app/src/main/res/values-fa/`

## Build

1. Open the project in Android Studio.
2. Let Gradle sync.
3. Build a debug APK or push to GitHub Actions.

## Notes

- App name: **T0H1 Scanner**
- Package name: `com.t0h1.scanner`
- UI: Jetpack Compose + Material 3
- Scanner engine: Python through Chaquopy
- Min SDK: 26
- Python version: 3.13
