
# T0H1 Scanner

Native Android app built with Kotlin + Chaquopy.

## Project layout

- `app/src/main/java/com/t0h1/scanner/`
- `app/src/main/python/scanner/`
- `app/src/main/res/`

## Build

1. Open the project in Android Studio.
2. Let Gradle sync.
3. Build a debug APK.

## Notes

- App name: **T0H1 Scanner**
- Package name: `com.t0h1.scanner`
- UI: native Compose, Material 3, dark theme
- Python: Chaquopy, under `app/src/main/python`
- Min SDK: 26
- Python version: 3.13
